# Mein Weinkeller

Erster Prototyp einer privaten Weinkeller-App.

## Enthalten
- Rotwein / Weißwein / Süßwein
- Winzer, Region, Jahrgang
- Bestand, Einkaufspreis, Händler
- Bestand um eine getrunkene Flasche reduzieren
- Verkostungsnotiz mit Datum
- Suche und Filter
- vorbereitete Felder für Bewertung, Trinkreife und Marktpreis

## Geplant
- Etikett-Foto + automatische Erkennung
- Internetquellen für Bewertungen und Trinkfenster
- Marktpreis-Abgleich
- Excel-Import
- persistente Datenbank / Benutzerkonto

## Start
```bash
npm install
npm run dev
```
